hexo首页分类磁贴实现

发表于2026-08-04|更新于2026-08-19|hexo
|浏览量:

目标效果

  • 首页文章列表上方展示分类卡片网格（默认 3 列 × 2 行）
  • 每张卡片显示：分类名、文章数、描述文案、背景封面
  • 点击卡片进入对应分类页（兼容 Pjax）
  • 封面优先走图床 CDN，失败自动回退本地 cover* 图
  • 描述按分类名绑定，不因 Hexo 分类排序变化而错位

安装插件

博客根目录：

主题配置

文件：themes/butterfly/_config.yml

说明

name + descr，脚本按名匹配后再按分类顺序输出

cover 由 category_bar_cover.js 从封面池自动写入

custom_css 改为 elemecdn

新增分类时，文章 front-matter 写好 categories后，在上面的 message 里加一条同名 name 即可；未配置 name 时描述回退为分类名本身。

日常维护

  1. 新分类

    • 文章写 categories: xxx
    • 在themes/butterfly/_config.yml文件中的 categoryBar.message 增加：

  2. 换封面

    • 改 source/_data/covers.yml，或增减 source/img/cover*
    • 无需再给每个分类（-name：… descr：…）手写 cover:

  3. 开关

    • 在themes/butterfly/_config.yml文件中找到categoryBar.enable: false 即关闭磁贴

      （本地封面回退脚本仍会注入；若也要关掉，需改 category_bar_cover.js 的 injector 条件）

  4. 样式 CDN 挂了

    • 把 node_modules/hexo-butterfly-categories-card/lib/categorybar.css 拷到 source/css/，把 custom_css 改成 /css/categorybar.css
