PicGo+github图床配置

1.配置github

1.github新建一个仓库保存图片。

2.生成私人令牌并复制保存（关闭页面后就看不到令牌了）

2.配置PicGo

1.下载并打开PicGo设置，滑到底部，在请选择显示的图床中只勾选github

2.点进图床设置，编辑配置信息。

仓库名 = github仓库的Repository名称，分支名为main

Token = 保存的token序号

存储路径空着，如果需要指定将图片存储到仓库中的某个路径下，就在这里设置即可。

自定义域名使用 https://cdn.staticaly.com/gh/【github用户名】/【github图床仓库名】@main获取加速。
